Introduction and History

Rust is a modern systems programming language primarily developed by Graydon Hoare while he was at Mozilla Research in 2006. Its first stable release was in 2015. It focuses on safety, concurrency, and performance without a garbage collector (an automated memory management technique used in many programming languages to reclaim memory occupied by objects that are no longer in use). Rust is used by companies like Dropbox, Cloudflare, and Microsoft. It is also used in NASA's core flight system, "The Rust language is designed to be memory-safe: it detects a wide range of programmer errors at compile-time while allowing low-level access to hardware and high performance."

Fibonacci Generator

fn fib(n: u32) -> u32 {
          match n {
              0 => 0,
              1 => 1,
              _ => fib(n - 1) + fib(n - 2),
          }
      }

Advanced Example

Multithreaded Web Server (Simple)

use std::net::TcpListener;
use std::thread;

fn main() {
    let listener = TcpListener::bind("127.0.0.1:7878").unwrap();
    for stream in listener.incoming() {
        thread::spawn(|| {
            let _ = stream.unwrap();
            println!("Connection received!");
        });
    }
}
